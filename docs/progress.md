- agbcc lessons from this batch (details in `docs/skipped.md`): a struct store of a 16-bit
  constant, `spr->unk4 = K`, expands to `(unk4 & 0) | K`, and inside a loop the zero can be
  hoisted into a spare register or a stack slot; `((u16 *)spr)[2] = K` does not do that.
  A clamp the optimizer would fold (`x = (x <= 0) ? 0 : x` on a u16) survives as in the
  original when the test reads a copy: `value = x -= step; x = (value <= 0) ? 0 : x;`.
  Copying a parameter into a local (`u32 bits = value;`) changes which of the two gets the
  argument register.
